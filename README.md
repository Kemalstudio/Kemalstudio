## A little about me

I’m **Kemal**, a full-stack developer from **Turkmenistan 🇹🇲**. I build web and mobile applications and work hands-on with **servers and networking** — using **Termius**, configuring **Cloudflare**, working with **DNS and VPNs**, and managing environments through **virtual machines**.

Alongside this practical work, I’m developing my **DevOps automation skills** and **learning Kali Linux and security fundamentals**. My long-term direction is **Security Engineering**, building on both application development and server administration.

I enjoy understanding a project from the application code to the server and network settings that keep it running.
